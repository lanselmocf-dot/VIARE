# VIARE — Plataforma de Turismo e Hotelaria

Protótipo front-end de uma plataforma de turismo e hotelaria, desenvolvido com **HTML**, **CSS** e **JavaScript** puros — sem frameworks, bundlers ou dependências externas.

## Tecnologias Utilizadas

- **HTML5** — estrutura semântica das páginas
- **CSS3** — estilização com variáveis CSS nativas (`:root`) e layout responsivo via Flexbox/Grid
- **JavaScript (ES5/ES6)** — lógica de interação, validação de formulários e persistência via `localStorage`
- **Google Fonts** — fonte Inter (carregada via `@import` no CSS)

## Como Executar

1. Faça o download ou clone do repositório
2. Abra o arquivo `index.html` diretamente no navegador

> Não é necessário instalar nenhuma dependência, servidor local ou ferramenta de build.

## Páginas do Projeto

| Página | Arquivo | Descrição |
|--------|---------|-----------|
| Login | `index.html` | Tela de autenticação do usuário |
| Registro | `registro.html` | Criação de nova conta |
| Hospedagens | `hospedagens.html` | Busca e listagem de hotéis com filtro por preço |
| Viagens | `viagens.html` | Pacotes de viagem completos |
| Ofertas | `ofertas.html` | Promoções e descontos especiais |
| Pagamento | `pagamento.html` | Finalização de compra com resumo do pedido |
| Reservas | `reservas.html` | Acompanhamento das reservas do usuário |
