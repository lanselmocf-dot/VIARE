# Créditos e Atribuições

## Design

O design visual deste projeto foi inspirado no protótipo original criado no Figma, que utilizava componentes do [shadcn/ui](https://ui.shadcn.com/) (licença MIT) e fotos do [Unsplash](https://unsplash.com) como referência estética.

> **Nota:** A implementação final não utiliza nenhuma biblioteca ou componente externo. Todo o código foi desenvolvido exclusivamente com HTML, CSS e JavaScript puros.
